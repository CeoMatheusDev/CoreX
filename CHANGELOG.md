# Changelog

This file records notable CoreX product changes. `VERSION` is the product-version authority; the changelog does not create or imply a release. Historical implementation notes are kept separately in [`docs/CHANGES.md`](docs/CHANGES.md).

## Unreleased

- Added a flat Q16.16 `LocalTransform3D` content codec and explicit `serializeAuthored` to omit computed/transient 3D state. Checked matrix arithmetic and dirty propagation report overflow, retain retry markers and support implicit identity through untransformed hierarchy nodes; legacy APIs remain available.
- Connected static 3D content to the read-only headless Runtime, calculating world matrices parent-first during setup only. A separate optional checksum suffix covers local/computed matrices and dirty state; checksums without 3D remain unchanged. Raw derived components and invalid/overflowing matrices fail explicitly; no dynamic transform updates, gameplay or rendering are implied.
- Connected read-only content hierarchy to the headless Runtime. Parent handles and ordered children contribute to a versioned checksum extension, while smoke/flat checksums remain unchanged; child slices are freed on success and error.
- Replaced headless position and age arithmetic traps with checked `PositionOverflow` / `AgeOverflow` errors; a failed tick is not transactional and the run stops without a final report.
- Restored the original `markDirty` ancestor markers and best-effort void behavior. Added a checked ancestor-marking API while preserving subtree-only `tryMarkDirty`, with retry, cycle, OOM and allocation-free repeat coverage.
- Extended content-scene JSON with optional parent and sibling file indices. Round-trip preserves generational handle remapping and child order; forward parents, cycles, malformed links, allocator failure and cleanup are covered. Flat descriptors remain unchanged; older strict parsers cannot read the new fields.
- Fixed dirty 3D propagation for reversed entity order and overlapping marks; added fallible/retryable APIs while retaining the original void signatures. Empty propagation allocates nothing; work includes affected subtrees and ancestor walks, not a general O(dirty) bound.
- Corrected negative Q16.16 rounding shared by 2D/3D transforms. Fixed hierarchy reparenting rollback and stale child-slice ownership, descriptor-parser cleanup, scene test leaks and Scene package file inventory.

- Added `scene/ecs/transform_dirty.zig`: dirty-flag propagation for 3D transforms; see the correction above for ordering, error handling, and complexity.
- Added `scene/ecs/transform3d.zig`: 3D affine transform hierarchy (ADR-003 scene_3d scope) with 4×4 `Mat4` in Q16.16 fixed-point, rotation LUTs around X/Y/Z, `LocalTransform3D`/`WorldTransform3D`, and `propagateTransforms3D` (world = parent.world × local). Deterministic integer math. Scene tests: 95/95.
- Extended `scene/ecs/events.zig` with handler lifecycle: `subscribe` now returns a `Subscription` token, plus `unsubscribe` (swap-remove, stale-safe) and `clear`. Handlers stored as optional slots so freed slots are reusable. Scene tests: 90/90.
- Added `scene/ecs/eventful_world.zig`: `EventfulWorld(Stores, bus_capacity)` wraps `World(Stores)` and auto-emits `entity_created`/`entity_destroyed`/`component_added<T>`/`component_removed<T>` into an `events.Bus`. Zero overhead with no subscribers; `World` untouched. Scene tests: 87/87.
- Added `scene/ecs/events.zig`: synchronous fixed-capacity event bus (`Bus(capacity)`) for entity/component lifecycle events (`entity_created`, `entity_destroyed`, `component_added<T>`, `component_removed<T>`). Registration-order dispatch, first-error stops, no allocation in the hot path. Optional and decoupled from `World`. Scene tests: 83/83.
- Added `scene/ecs/transform2d.zig`: 2D affine transform hierarchy with rotation and scale via fixed-point Q16.16 integer math (deterministic, no floats in the hot path). `Mat2x3` (2x3 matrix with 360-entry sin/cos LUT), `LocalTransform2D`/`WorldTransform2D` components, `propagateTransforms2D` composing parent world × local. Scene tests: 79/79.
- Extended `scene/ecs/query.zig` with NOT exclusions: `each`/`count`/`Iterator` now take a second tuple `NotT` of excluded component types (e.g. `each(WorldT, world, .{Position}, .{Velocity}, cb)` matches entities with Position but without Velocity). Scene tests: 74/74.
- Added `scene/ecs/transform.zig`: transform hierarchy with `LocalTransform` and `WorldTransform` components, propagated through the parent/child graph via `propagateTransforms` (roots: world=local; children: world=parent.world+local). Built on `hierarchy.zig`, no World changes. Scene tests: 72/72.
- Added `scene/ecs/query.zig`: allocation-free multi-component queries (`each`, `Iterator`, `count`) over any `World(StoresT)`. The first type in the query tuple drives iteration (put the rarest component first); remaining types are probed with O(1) sparse-set lookups. Scene tests: 68/68.
- Added `scene/ecs/hierarchy.zig`: parent/child entity hierarchy as regular `SparseSet` components (`Parent`, `Children`) with cycle-safe reparenting, root detection, and `onDestroy` child reparenting to the grandparent. Any `World(Stores)` declaring these components gets hierarchy. Scene tests: 65/65.
- Added `scene/content_serializer.zig`: deterministic JSON serializer that writes any `World(StoresT)` back to the content-scene format (entities in index order, components in store declaration order). Round-trips with `content_loader` (load → serialize → load preserves state). Replaced the `Scene.saveDescriptor` stub with the real implementation. Scene tests: 60/60.
- Connected the content-scene loader to the Runtime headless executor: new `--scene <file>` CLI flag (Runtime-only, requires `--headless --frames N`), `RunRequest.scene_path`, and `run_mode.Request.io`. When set, the scene is parsed via `scene.content_format` and loaded via `scene.content_loader` instead of the embedded smoke scene; logs report `scene="content"`. Verified end-to-end: 2-entity scene file → `entities_alive=2`.
- Added a real content-scene file format and loader to `corex_scene`: `scene/content_format.zig` (strict JSON parser with caller-owned memory, rejects unknown fields/floats/zero capacity) and `scene/content_loader.zig` (generic loader that populates any `World(Stores)` from a parsed descriptor, matching component kinds to store fields by name). 57/57 Scene tests pass.
- Adopted `corex_core` in the Editor: added `editor/src/editor_session.zig` with a concrete `editor.session` subsystem (document load → scope policy → distribution verification → ready) registered into a `core.subsystem.Registry(4)`, plus `EditorLifecycle` in `editor_lifecycle.zig`. The Editor now consumes the shared Core lifecycle; 40/40 Editor tests pass.
- Added the root `VERSION` authority, strict native Zig parsing/comparison, validated release transitions, and the `corex-version` CLI with dry-run support.
- Injected the CoreX product identity into the root, Editor, and Runtime builds and added `--version` to the application executables.
- Generated and validated a distribution manifest with an explicit project-version compatibility allow-list; centralized Editor/Runtime compatibility classification and corruption/invalid-distribution diagnostics.
- Improved the CoreX Zigway adapters with explicit platform options and forwarding for window, event, input, and capability operations; added headless integration tests.
- Replaced obsolete Zigway tests and connected the adapter test artifact to the root test step.
- Reorganized and clarified project READMEs, architecture/status documentation, and the ADR index.
- Recovered the legacy ECS system contract and the legacy memory and Lua allocator modules for Zig 0.17.0; they are now compiled and covered by 15 new tests, and their paths are part of the formatting gate. They remain unused by the Editor, Runtime, and legacy executable.
- Preserved package SemVer, `.proj` schema versions, renderer contract, graphics ABI, dependency pins, and Zig 0.17.0 as separate version domains.
- Replaced the placeholder pool descriptor in the legacy core with a working `PoolAllocator` (fixed blocks, alignment-aware stride, LIFO reuse, invalid-free detection, fixed capacity) and added a `PoolRegistry` that reuses pools per geometry and routes frees to the owning pool, covered by 11 new legacy tests. Both remain unused by the Editor, Runtime, and legacy executable.
- Added the `core/` package (`corex_core`): a dependency-free lifecycle state machine and a fixed-capacity subsystem registry with registration-order start, exact reverse teardown, rollback of already-started subsystems on failure, and no allocator in the step path. The Editor does not consume it yet; the Runtime does.
- Added an opt-in deterministic headless execution mode to the Runtime (`--headless --frames N`, 1..1000000): the existing fixed-step scheduler and input tick buffer now run inside a real loop with a virtual 60 Hz clock, no window, GPU, scene or presented frame, and four cross-checked counters. `shared` only defines the runner contract, so an application without one still reports `application.core_unavailable`.
- Added the `scene/` package (`corex_scene`), depending only on `corex_core`: generational `Entity` handles with LIFO slot reuse, `SparseSet(T)` component storage with O(1) lookup and swap-remove, generic `World(Stores)` resolved at comptime without type erasure or hash lookup, deterministic `Systems(WorldT)`, and `Scene(WorldT)` reusing `core.lifecycle.Lifecycle`. It has 46 tests and no renderer, window, assets, scripts, physics, jobs or threads.
- Connected a declared smoke Scene to the Runtime headless executor as `runtime.scene`, between `runtime.input` and `runtime.ledger`. The allocator comes from `main` through `Runner.context`; the scene is populated after `registry.start()`; `entities_alive` and `state_checksum` (FNV-1a 64, entity index order) are reported in `runtime.run_complete` and `shared.bootstrap.RunReport`. This is not gameplay or content-scene loading.
- Extended the native integration suite with 2 execution cases (35 total) and then 2 final-state/determinism cases (37 total); documented the new report fields, `scene="smoke"`, and the embedded smoke-scene limits.
- Added [ADR-007](docs/ADR-007-entity-sparse-set-and-memory.md) and [ADR-008](docs/ADR-008-scene-lifecycle-and-runtime-integration.md), plus a Scene README and updated architecture/status/CLI/layout documentation.
- Added a native Zig port of the Editor/Runtime integration suite (`tools/zig/test_bootstrap_cli.zig` plus the test-only `bootstrap_probe.zig`): 33 black-box tests over real processes, JSONL, distribution integrity, deadlines, capture limits, and child cleanup, runnable with `zig build test-bootstrap-cli` on POSIX hosts. The Python reference remains in CI until remote validation.

No product release is created by an Unreleased entry. Release procedures are defined in [`VERSIONING.md`](VERSIONING.md).
